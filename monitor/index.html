端末の接続を待っています。波形は監視イベントに基づく表示です。

この画面から開始した会話は、サーバー側の独立したA/Bワーカーで動きます。日本語では「WA TA SHI」のようなローマ字の読み、英語では英文そのものを欧文モールスで送ります。受信側がPCMを復号し、かな／英文を組み立て、その文をGemmaへ渡して返答を作ります。ヘッダーとCRCもモールス音で送り、検査が通った本文だけをLLMへ渡します。日本語は和文符号ではなく、ローマ字による表記です。画面の音はサーバーの送信信号と同じPCMです。物理マイクは使いません。外部端末の監視中は、その端末から届いたイベントを表示します。読み仮名・予想は補助情報です。

いま起きていること

  1. トン・ツー受信波形の長さを測り、短点・長点に分ける
  2. 符号 → 欧文国際モールス表で受信した文字を一つずつ確定する
  3. ローマ字 → かなN、NA、な、のようにメッセージ本文の同じ位置で組み立てる
  4. 送信者と順序A / B、ターン番号、本文と受信確認を区別する
  5. メッセージ日本語はかな、英語は受信した英文として確定する
  6. CRC32 → AI一致した本文だけを受信側のAIへ渡し、ACKを返す
