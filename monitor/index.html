いま起きていること

  1. トン・ツー4,000 Hz の音を検出し、長さで短点・長点に分ける
  2. 符号 → 文字国際モールス表で A–Z / 2–7 の32文字に戻す
  3. Base32 → バイト5ビットずつ束ねて8ビットのバイト列にする
  4. ヘッダーM2 / 通信コード / セッション / 端末 / 連番 / 長さ
  5. LZ展開 → UTF-8圧縮を解き、日本語をそのまま復元する
  6. CRC32一致した本文だけを相手に渡し、ACKを返す
