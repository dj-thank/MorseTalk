# MorseTalk · Signal School

既存MorseTalkに追加する、人がモールス信号を覚えるための学習モードです。MT1/MT2の高速端末間通信とは分離しています。

## 開き方

AI Link画面の「モールスを覚える · SIGNAL SCHOOL」を押します。Windowsは従来のStart-AI-Windows.cmd、Androidはこの変更を含むAPKからAI Linkへ進みます。学習モードはai.htmlと同じ信頼済みドキュメント内に表示され、ネイティブ権限や通信プロトコルを追加しません。通信・モデル処理中は入口をロックします。

AIを使わずに学習するには `node tools/build_academy_preview.mjs` で生成される `dist/MorseTalk-Signal-School-Preview.html` を開きます。このHTMLにモデル、代替のAI応答、外部アセットは含みません。

## 練習

「音で覚える」は最初の2文字から始め、4/8/16/全文字へ手動で範囲を増やします。未学習・間違えた・復習予定を過ぎた文字を重み付けして出題します。欧文A–Zと数字、和文かなに対応します。符号帳では既存コーデックの全対応文字を確認・再生できます。

文字速度8〜40 WPMと、実効速度5 WPM〜文字速度を別々に選べます。短点・長点を保ったまま文字間を広げるFarnsworth方式です。PARISの固定部分31単位、間隔部分19単位から計算しています。従来の高速AIリンクの速度設定は変更しません。

「打ってみる」はタッチ／マウス／Spaceの押下時間を短点・長点として復号します。点・線の平均時間誤差も表示しますが、区切り全体のリズムは採点していません。長押し継続、pointercancel、フォーカス喪失、画面非表示では停止します。補助ボタン、答え表示、再聴取は補助ありとして記録し、習得判定には含めません。

「腕試し」は10問の受信自主テストです。公的資格試験ではありません。挿入・欠落・置換を整列して判定し、1文字の欠落が後続全ての誤りにならないようにします。得点は補助なし完全一致の問題数です。途中のページ移動でテストは終了します。

## AIと実際に練習する

「接続・モデル」から既存の設定に戻り、導入済みモデルと送信許可を確認します。学習用の別キー保存や新しい外部サーバーはありません。既存のgenerateReplyを使用し、Android端末内Gemma／WindowsのローカルAIなど既存の経路を共用します。設定した外部AIを使う場合は会話がその送信先に渡ります。自動でクラウドへ切り替えません。

会話経路は、打った信号→厳密な復号→指定モデルの生成→対応文字・長さの検査→モールス音の順です。返信文字は最初に隠し、「答えを見る」で確認できます。英文は48文字、和文は24文字を上限にし、変換不能・長過ぎ・空の応答は切り詰めずエラーで止めます。モデルが制約を守れなかった場合は短い会話で再試行してください。固定文への代替はしません。

AI聞き取り試験では指定モデルが短い文を生成・送信し、人が聞き取って入力します。正誤はモデルの自己申告ではなく同じ決定的な採点器で判断します。会話履歴は直近10メッセージ、12往復まで。停止・リセット時は遅れて届いた返答を破棄します。

Androidの音声入力ボタンは既存の端末内認識を呼び出し、認識文を編集欄に入れるだけです。結果を確認してから変換・送信します。和文は漢字をかなに直してください。音声認識や実端末の推論速度をこの変更のローカルテストで検証したわけではありません。

これは1台での学習です。別端末とのマイク通信や無線電波による送信ではありません。従来の音響／オンライン通信には「通信に戻る」を使います。

## 記録・プライバシー

進捗はバージョンと境界を検証してlocalStorageに保存します。保存が許可されないブラウザでは警告を出し、画面内で保持します。JSON書き出しにも対応します。会話本文は学習統計に保存しません。習得済みは受信または送信で補助なし3回以上正解し、80%以上の文字です。統計は実際の練習から増え、架空の連続日数などは表示しません。

## デザイン素材

生成画像の方向性は、アイボリー・深緑・真鍮の電鍵と点／線、柔らかい余白。Runway nano-banana-2で参考画像を1枚生成しました（task: f8686afc-464e-4fd9-8484-ef74486b4556）。生成されたラスター画像自体はこのソースに含まれていません。期限付きURLに依存しないよう、同系統の独自SVGイラストをacademy-view.mjsに内包しています。外部フォント・画像CDN・UIフレームワークは追加していません。

## 検証を再現する

```
node --test tests/academy.test.mjs
node tools/build_academy_preview.mjs
python -m pip install playwright==1.57.0
python -m playwright install chromium
python tools/test_academy_ui.py
```

既存Chromiumを使う場合はCHROMIUM_PATHを指定します。UIテストはネットワークを使わず、実際のChromium描画とWeb Audioで実行します。NativeBridgeとStorageだけは明記したテストダブルです。保存形式の往復は単体テストで検査します。実LLMの成功、物理スピーカー／マイク、実Android推論、オリジン付きブラウザ保存の実測とは区別してください。

実モデル検証は、導入済みOllamaを明示して次を実行します。6回の生成上限があり、自動モデルダウンロードはしません。

```
MORSETALK_AI_MODEL=gemma4:e2b-it-qat node tools/test_academy_model.mjs
```

GitHub ActionsのSignal Schoolワークフローには、UIのテストダブル検証と実Gemmaの会話／出題検証を別ジョブで用意しています。CIの合否は各実行結果で確認してください。既存の完全ビルド・APK・回帰テストのワークフローも変更せず残しています。
