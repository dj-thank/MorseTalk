## 改善した操作と動作

- 準備カードでモデル・AI処理の許可・端末A/Bと通信設定を確認できます。画面内リンクと固定の「すべて停止」で、長い画面でも停止操作へ到達できます。
- モデル取り込みの実コピー量・全体量・端末空き容量を表示します。全体量が不明なら割合を表示しません。モデルの入手先は明示操作でGoogleの説明を外部ブラウザに開きます。ダウンロードによる数値付き重複名 (1) などは受け付けますが、GGUF・別モデル・パス指定は拒否します。名前だけで出所や実行可能性を保証しません。
- 接続コード `MT2|0000|AABBCCDD|120|8|180` は通信コード・セッション・速度・ターン上限・応答バイト上限をまとめて渡します。全項目検査後に反映し、役割、AI接続先、モデル、許可、本文は変更しません。適用しても推論・録音を自動で始めません。Bluetoothペアリングや相手認証・暗号化ではありません。
- 編集可能な話題のひな型、到達ターン・再送・経過時間を追加しました。経過時間には準備と待機を含み、片道の信号長や推論単体とは異なります。
- 診断JSONは停止後に明示保存。既定で本文を除き、含めるときだけチェックを使います。生のエラーメッセージ、設定済みAIエンドポイント、認証トークンを出力しません。400イベントまでメモリ内に保持し、自動保存・外部送信はありません。本文を含める場合、そこに個人情報が入る可能性があります。
- 停止後もネイティブworkerが実際に終わるまで次の処理を拒否します。古いpreloadの失敗が新しい操作を上書きする競合を修正しました。
- 同じフレームの予約中ACKを共有し、ACKキューを4件に制限。混雑で受け付けなかったフレームは連番を進めず、再送で処理できます。MT1/MT2の通信形式は維持しています。

## 端末内Gemmaの実測

LiteRT-LM0.17.0、CPU2スレッド、Android15/API35 x86_64エミュレーター、RAM6GiB。
モデル読み込み5.813秒。1回目「懐中電灯」は3.715秒、2回目「非常食」は1.865秒で、2回目の履歴キャッシュ再利用を確認しました。
実モデルの4ターンを生成→モールスPCM化→復号→次のAI入力へ渡し、生成中キャンセルも成功しました。このAndroid内のPCM試験は数値処理で、実時間の音声再生・収録ではありません。同一アプリ・同一モデルを2役に使います。
Wi-Fiとモバイルデータを止め、HTTP推論やADB reverseなしで実行しました。モデル配置は検証スクリプトで行い、配布元と配置先のハッシュを照合しています。手動取り込みUIのidentityVerified:falseを、配布元を自動認証済みという意味に読み替えません。

## 途中の失敗と最終修正

ブランチ実行34574446846はライセンス検証で失敗しました。元画面のリンクにもある文言だけで到着を判定できるテストを、正確なURLと文書準備完了の両方を確認する方法へ修正しました。
さらに、遅れて完了したネイティブ結果を表示専用ページに渡さないガードをJava側とJavaScript実行時に追加しました。表示専用ページの権限付き要求と故意に遅らせた応答を拒否し、AI画面へ戻る操作を3回繰り返す回帰検証を両Androidジョブで通しました。元の失敗を外部攻撃の実証とは扱いません。
WindowsのPASS行はActionsコンソールで確認。windows-evidenceはsource-commit.txtのみで、Write-HostはTee-Objectへ収録されていません。配布ログの抜粋を全文ログとは扱いません。
Lintの4警告はtarget API、データ抽出設定、CursorとInputStreamの解放に関するものです。

## 導入と残る範囲

AndroidはAPKをインストールし、モデルの入手先からgemma-4-E2B-it.litertlmを取得。取り込む→CPU→AI処理の許可→先に読み込む→AI接続テスト。元ファイル約2.59GBとアプリ用コピー、合計約5.2GBに加え容量の余裕が必要です。
2台は120WPMから。Aで新しいセッション→接続コードをコピー、Bで適用。役割をA/Bに分け、B待機→A待機→A開始です。
WindowsはGemma対応のローカルOllamaにOLLAMA_NO_CLOUD=1を反映し、ollama pull gemma4:e2b-it-qat。Python3.10以降でStart-AI-Windows.cmdを使います。Androidの.litertlmはOllamaへ流用しません。
異なるデバッグ署名で旧版に上書きできない場合、削除でモデル・履歴が消えるため必要なデータを先に保存してください。
物理2台の空気中通信・距離・反響・雑音、Pixel9a/GPU、実音声ASR/TTS、2.59GBファイルの選択からコピーまでの実端末操作一式は未検証です。
重み同梱、暗号化・相手認証、ストア配布用署名はありません。秘密情報や緊急通信に使わないでください。
