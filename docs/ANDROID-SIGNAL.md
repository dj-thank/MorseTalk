# Android Signal — 2台の実音響会話

Androidの起動画面に、A/Bの波形・メッセージ・自分の推論要約を表示するSignal画面を追加しています。相手の非公開な推論を取得したようには表示しません。受信文字はローマ字からかなへ進み、CRCが通った後に漢字かな交じりへ変換します。

メッセージとACKは、相手を左、自分を右に配置したチャットで表示します。各吹き出しは送信者・通信番号・種類に紐づき、再送や遅れて届く文字で次のメッセージを書き換えません。上部のA/B欄は待機・推論・送信・受信・ACKを区別します。送信文字は実際の音声再生クロックに合わせて現れます。

ACKには「受信しました」の読みを実際にモールス本文として載せます。各端末は自身のマイクで受けたACKを、通常のメッセージと同じくローマ字→かな→漢字へ復元します。先頭の信号、ヘッダー、末尾の検査部分もアルファベットとして表示し、不明な符号は「不明」と残します。主受信器の未検証の読取結果と、いずれかの受信器がCRC検証した本文を区別して保持します。相手の画面状態や既知の定型文で受信表示を補いません。ACKはLLMへの会話入力にはせず、推論要約は音声送信しません。

## 構成

各スマートフォンが自分の会話履歴、送信キュー、マイク、モールス復号器を持ちます。送信側のスピーカーから出た1,800 Hzの音を、相手のマイクとAudioWorkletが読み取ります。CRCを確認した受信文だけを、受信端末が次のGemma入力にします。ACKも逆向きの音です。USB／無線ADB経由で相手の本文やPCMを転送する経路はありません。

この画面の推論先はPCのGemma 4 E2Bです。モデル呼出しと読み・IME変換にADB reverseを使います。Android端末内のモデルだけで完結するモードではありません。従来の端末内モデル／オンライン設定は右上の「設定」から開けます。

## 準備

1. PCのLM Studioで `gemma-4-e2b-it` を読み込み、`127.0.0.1:1234` の互換APIを起動します。
2. 読み変換用Pythonへ `requirements-monitor-reading.txt` を導入し、`MORSETALK_READING_PYTHON` をそのPython実行ファイルに設定します。
3. `Start-Monitor.cmd --port 18790` を起動します。
4. 2台へ同じAPKを上書きインストールします。署名が違う場合は削除せず、元の署名を確認してください。
5. 各端末について `adb -s SERIAL reverse tcp:1234 tcp:1234` と `adb -s SERIAL reverse tcp:18790 tcp:18790` を設定します。無線ADBで接続した端末にも同じ設定を使えます。

## 会話

2台を近くに置き、片方をA、もう片方をBにします。話題とWPMを合わせ、まず20 WPMで試します。アプリの音量に加え、端末のメディア音量も確認します。Bの「受信をはじめる」、Aの「受信をはじめる」、Aの「Aから話す」の順に操作します。マイク権限が必要です。役割・話題・速度・アプリ音量は次回のために保存します。

デバッグAPKでは `python tools/android_signal_pair.py --a SERIAL_A --b SERIAL_B --wpm 20 --start` で同じ画面操作を実行できます。事前に端末上でマイク利用を許可してください。

停止まで交互に会話します。アプリを背景に移した場合もマイクと推論を停止します。受信失敗は実際の失敗として表示し、誤った文を正解に差し替えません。高いWPMを自由入力できますが、距離・反響・周囲の音・端末の音量によって失敗することがあります。

## 実機確認

2026-09-13時点で、Pixel 9aとPixel 7へのデータを保持した上書き更新、Signal画面・ネイティブ連携・AudioWorkletの起動を確認しています。

0.6.3の実音響試験では、20 WPM、アプリ音量100%、端末メディア音量最大の条件で、A→B→A→Bの4回の本文配送、両方向のACK本文「じゅしんしました」、受信した本文からの実Gemma入力、明示停止を確認しました。送信側のかなと受信側のCRC検証済みかなが一致しています。

これは当該2台・当該設置条件での確認です。長時間放置、高速設定、騒音や距離を変えた場合の安定性を保証するものではありません。4回配送を確認した後の新規開始でも受信失敗による再送が発生しており、安定性にはばらつきが残ります。画面テストや合成PCM試験を、実音響試験の代わりにはしません。
