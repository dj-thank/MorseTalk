# MorseTalk

音声 ↔ モールス、AI ↔ 音響モールス ↔ AI。Windows と Android 用の実験的翻訳・通信アプリです。

このリポジトリは会話で作成した MorseTalk AI Link 0.2.0 を取り込み、APK生成・実AI・ブラウザ音声処理・Androidエミュレーター検証を再現可能にするための開発先です。

検証済み項目と未検証項目は検証レポートおよび GitHub Actions の実行結果で区別します。数値PCM試験は実際のスピーカー／マイク間通信の証明ではありません。
